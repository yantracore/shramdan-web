## Lifecycle (पाँच पाइला)

1. **समस्या Report हुन्छ** — कोही नागरिकले आफ्नो टोलको समस्या (फोहोर, टुटेको पाइप, बत्ती नभएको गल्ली, etc.) तस्बिर र स्थान सहित दर्ता गर्छन्।
2. **समुदायले Vote गर्छ** — छिमेकीहरूले महत्त्व देखाउँछन्। Threshold पुगेपछि issue *campaign-ready* हुन्छ।
3. **Campaign तय हुन्छ** — Leader चयन, मिति-समय-स्थान तय, role assignment (Volunteer, Photographer, Livestreamer, Safety lead, etc.)।
4. **Event हुन्छ** — सबै मिलेर काम गर्छन्; YouTube Live मा प्रसारण।
5. **Result Publish हुन्छ** — Before/after, सहभागी सूची, खर्च — सब transparent।
